# Ответы к лабораторной работе 5

## 1. Фильтры конечной точки

Фильтр конечной точки в ASP.NET Core Minimal API - это обработчик, который выполняется до и/или после основного обработчика маршрута. Фильтр получает `EndpointFilterInvocationContext`, может читать аргументы обработчика, `HttpContext`, заголовки и другие данные запроса.

Принцип работы похож на цепочку: каждый фильтр либо вызывает `next(context)` и передает запрос дальше, либо сразу возвращает результат, например `Results.Conflict(...)`, `Results.NotFound(...)` или `Results.Problem(...)`. Благодаря этому фильтры удобно использовать для проверки входных данных, авторизации, логирования, добавления заголовков и централизованной обработки ошибок.

В лабораторной работе фильтры проверяют данные новой знаменитости перед `POST /Celebrities`: корректность `Surname`, отсутствие дубликата фамилии и наличие файла фотографии. В `ASPA005_1` фильтры заданы inline через `AddEndpointFilter(...)`, а в `ASPA005_2` вынесены в классы, реализующие `IEndpointFilter`, и подключены через `AddEndpointFilter<TFilter>()`.

## 2. Констрейнт маршрута

Констрейнт маршрута - это ограничение на значение параметра в шаблоне маршрута. Он указывается в фигурных скобках после имени параметра, например `{id:int}`, `{x:range(0,100)}` или `{email:regex(...)}`. Если значение из URL не проходит ограничение, маршрут не считается подходящим и запрос обрабатывается другим маршрутом или fallback-обработчиком.

Основные констрейнты маршрутов:

- `int`, `long` - значение должно быть целым числом соответствующего типа.
- `float`, `double`, `decimal` - значение должно быть вещественным числом соответствующего типа.
- `bool` - значение должно быть `true` или `false`.
- `datetime` - значение должно преобразовываться в `DateTime`.
- `guid` - значение должно быть корректным GUID.
- `min(value)`, `max(value)` - числовое значение должно быть не меньше или не больше заданной границы.
- `range(min,max)` - числовое значение должно находиться в заданном диапазоне.
- `minlength(value)`, `maxlength(value)`, `length(value)`, `length(min,max)` - ограничения длины строки.
- `alpha` - строка должна состоять только из букв.
- `regex(expression)` - значение должно соответствовать регулярному выражению.
- `required` - параметр должен быть указан при генерации URL.

В `ASPA005_3` констрейнты используются для отбора маршрутов `/A`, `/B`, `/C`, `/D`, `/E` и `/F`: например, `/A/{x:int:range(0,100)}`, `/E/{x:alpha:length(2,12)}` и `/F/{x:regex(...)}`.
